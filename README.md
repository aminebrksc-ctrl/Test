# Starmah Telegram Bot — نسخهٔ اول

بات شخصی [@starmah_bot](https://t.me/starmah_bot) برای گفت‌وگوی فارسی و تولید تصویر از متن، با OpenAI API.

## امکانات

- گفت‌وگوی متنی با حفظ ۶ نوبت اخیر هر کاربر، مستقل از سایر کاربران
- دکمهٔ «🎨 ساخت عکس»، دستور `/image توضیح تصویر` و پیشوند `عکس:`
- `/new` برای پاک‌کردن حافظهٔ بات و `/id` برای نمایش شناسهٔ خودتان
- فقط کاربران مجاز، فقط گفت‌وگوی خصوصی، پیش‌فرض بسته به همه
- صف SQLite، جلوگیری از پردازش دوبارهٔ یک پیام و سقف روزانهٔ درخواست برای هر کاربر
- کلیدها فقط در متغیرهای محیطی؛ هیچ کلید واقعی در مخزن قرار نمی‌گیرد

## راه‌اندازی

کد به‌تنهایی بات را فعال نمی‌کند. به توکن BotFather، کلید OpenAI API با اعتبار و میزبان نیاز است. هزینهٔ API جدا از اشتراک ChatGPT است. این بات به تاریخچه، حافظه، ابزارها یا اشتراک شخصی ChatGPT دسترسی ندارد.

1. در Render سرویس Python را از همین مخزن بسازید. فایل `render.yaml` تنظیمات قابل تکرار را دارد؛ یا Build Command را `python -m compileall -q app.py` و Start Command را `python app.py` بگذارید.
2. در Environment، `TELEGRAM_BOT_TOKEN` و `OPENAI_API_KEY` را وارد کنید. این کلیدها را در چت یا GitHub نگذارید.
3. `WEBHOOK_SECRET` رشتهٔ تصادفی ۳۲ تا ۲۵۶ کاراکتری شامل حروف، عدد، `_` یا `-` است. Blueprint آن را تولید می‌کند. برای تنظیم دستی: `python -c 'import secrets; print(secrets.token_urlsafe(32))'`.
4. URL عمومی Render خودکار استفاده می‌شود. در میزبان دیگر `BASE_URL` را به آدرس HTTPS عمومی تنظیم کنید.
5. بعد از اجرا، به بات `/id` بفرستید. شناسهٔ عددی خود را در `ALLOWED_USER_IDS` وارد کنید و تغییرات Environment را ذخیره کنید. چند شناسه با ویرگول جدا می‌شوند. خالی بودن این مقدار یعنی هیچ‌کس اجازهٔ استفاده از API ندارد.
6. `/start`، یک پیام فارسی و سپس `/image یک گربهٔ فضانورد` را آزمایش کنید.

در شروع برنامه، توکن با `getMe` بررسی می‌شود و فقط نام کاربری `starmah_bot` پذیرفته می‌شود. سپس webhook و فهرست فرمان‌ها ثبت می‌شود. این کار مسیر دریافت پیام بات را به سرویس جدید تغییر می‌دهد؛ هم‌زمان برنامهٔ دیگری برای همین بات اجرا نکنید.

## محدودیت‌های نسخهٔ آزمایشی

- طرح Free در Render پس از بی‌کاری متوقف می‌شود؛ پیام بعدی ممکن است دیرتر پاسخ بگیرد. دیسک آن موقت است: تاریخچه، صف، جلوگیری از تکرار و شمارنده‌های مصرف بعد از توقف/راه‌اندازی مجدد یا استقرار پاک می‌شوند. سقف‌های مصرف روی این طرح تضمین هزینهٔ روزانه نیستند. برای استفادهٔ پایدار به دیسک ماندگار/پایگاه داده و میزبانی مناسب ارتقا دهید.
- اگر پردازش قطع شود، درخواست پولی خودکار تکرار نمی‌شود؛ ممکن است کاربر لازم باشد پیام را دوباره بفرستد. صف روی دیسک موقت هم ممکن است از دست برود.
- سقف‌های پیش‌فرض: ۱۰۰ درخواست متن و ۵ تصویر برای هر کاربر در روز UTC. درخواست ناموفق هم ممکن است سهمیه مصرف کند. بودجه و مصرف را در پنل API کنترل کنید.
- یک نمونهٔ سرویس و یک worker؛ برای استفادهٔ شخصی، نه ترافیک عمومی. ارسال تصویر با کیفیت low و اندازهٔ ۱۰۲۴×۱۰۲۴ است. مدل‌ها با `TEXT_MODEL` و `IMAGE_MODEL` قابل تغییرند؛ دسترسی مدل‌ها باید با کلید واقعی آزمایش شود.
- فعلاً ویرایش عکس ورودی، ویس، ویدئو و جست‌وجوی وب ندارد. تولید عکس از دکمه یا دستور انجام می‌شود.
- `/new` متن ذخیره‌شدهٔ گفت‌وگو را از برنامه پاک می‌کند؛ پیام‌های تلگرام و داده‌های نزد ارائه‌دهنده را حذف نمی‌کند. متن صف پس از پردازش پاک می‌شود. `/privacy` توضیح را به کاربر می‌دهد.

## توسعه و بررسی

Python 3.12+، بدون وابستگی اضافه:

```bash
python -m unittest discover -s tests -v
python app.py
```

فایل `.env.example` فقط راهنماست؛ برنامه فایل `.env` را خودکار بارگذاری نمی‌کند. تنظیمات را در Environment میزبان یا محیط اجرای محلی وارد کنید.

`/healthz` زنده‌بودن سرویس، ثبت webhook و وجود کلید API را گزارش می‌کند؛ وجود کلید به معنی تأیید اعتبار یا دسترسی مدل نیست.

آزمون‌ها با پاسخ‌های شبیه‌سازی‌شده اجرا شده‌اند؛ آزمون واقعی تلگرام و OpenAI پس از تنظیم کلیدها انجام می‌شود.
